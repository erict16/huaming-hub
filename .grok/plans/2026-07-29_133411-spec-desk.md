# Spec Desk Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax.

**Goal:** Make Huaming Hub a Spec Desk — home is the PDF workbench; series indexes into docs; cold paper tokens locked.

**Architecture:** Reuse `DownloadExplorer` on `/` and `/downloads`. Nav “Docs” points at `/` and stays active on both routes. Products deep-link `/?q=`. No stack change (Next static + GH Pages).

**Tech Stack:** Next.js 15 App Router · TypeScript · Tailwind v4 · static `output: 'export'`

## Global Constraints

- PDFs remain external (intl-huaming.com); no re-host
- EN default; Chinese under `/zh`
- No Email Desk links on hub
- No dark bands / marketing hero / howto
- Tokens match `design.md` / Spec Desk design doc
- Desktop search autofocus only (`min-width: 640px` via media or matchMedia)
- Copy: short, functional (avoid-ai-writing)
